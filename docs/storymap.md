# Story Mapping 拡張機能のストーリーマップ

ユーザーは「開発者」。\
開発対象への理解を深めるためにストーリーマップを作る。\
「コミュニティ」にマップを見てもらってフィードバックをもらうこともある。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. ユーザーが一通り使える
5. 見た目のカスタマイズ
