# Story Mapping 拡張機能のストーリーマップ

ユーザーは個人開発者。\
開発対象への理解を深めるためにストーリーマップを用いる。

- 拡張機能を準備する

  - [x] 拡張機能を.vsixファイルから直接インストールする
    - _
      - [x] 拡張機能をVSCode Marketplaceからインストールする
- マップを用意する
  - [x] テスト用のマップを用意する
    - [x] 新しいマップのMarkdownファイルを作る+
    - [x] 既存のアウトラインのMarkdownファイルをマップとして扱う
- アウトラインを書く+
  - ユーザーを書き出す
  - アクティビティを書き出す
    - [x] テスト用のマップを開く
      - [x] アクティビティを書き出す+
        - [x] アクティビティの順番を入れ替える+
          - [x] アクティブティ・タスクの階層を自由に決定できる

- タスクを書き出す
        -

      - [x] アクティビティの下にタスクを書き足す
                - [x] タスクの優先度（ネストの深さ）を変える

- その他
        -

            - [x] マップに関する補足事項は、アウトラインより上のパラグラフに書くことができる。
                - [ ] その他のメモを、アウトラインの下のパラグラフに書くことができる。
- マップを眺める
  - [x] 開いた時点のアウトラインを元にマップ表示のプレビューを開く
  - [x] タスクの完了チェックが反映される+
    - [x] 編集に追従してプレビューが即時更新される
    - [x] マップをズームする
      - [x] 補足事項はタイトルの下にパラグラフとして表示される。
        - [ ] その他のメモが、マップの下に表示される。
          - カードが紙に手描きしたように見える（気軽さ・温かみのため）
            - 倍率を手動で入力する
              - 設定で横軸ストーリーごとの色を変える
    - [x] ストーリーマップをPNGで保存する
- マップから実装を進める
  - [x] 最上段（Walking Skeleton）のタスク群を確認する
    - [x] 完了したタスクにチェックをつける+
    - [x] 次に実装するタスクを選ぶ
