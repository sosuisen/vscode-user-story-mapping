# Story Mapping 拡張機能のストーリーマップ

ユーザーは「開発者」。\
開発対象への理解を深めるためにストーリーマップを作る。\
「コミュニティ」にマップを見てもらってフィードバックをもらうこともある。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. ユーザーが一通り使える
5. 見た目のカスタマイズ

- 準備 #開発者
  - 拡張機能を準備する
    - [x] 拡張機能を.vsixファイルから直接インストールする
      - [x] 拡張機能をVSCode Marketplaceからインストールする
  - ファイルを用意する
    - [x] テスト用のマップを用意する
      - [x] 新しいマップ用のMarkdownファイルを作る
        - [x] ^ 既存のアウトラインのMarkdownファイルをマップとして扱う
- アウトラインを編集する #開発者
  - ユーザーを書き出す
    - [x] v 登場するユーザーはタイトルの下に普通のパラグラフとして書く
  - タスクを書き出す
    - [x] テスト用のマップを開く
      - [x] タスクを書き足す
  - アクティビティを書き出す
    - [x] v アクティビティを書き足す
  - アウトラインを組み替える
    - [x] v アクティビティの順番を入れ替える
      - [x] ^ タスクの必要性（インデントの深さ）を変える
        - [x] ^ アクティブティ・タスクのスライスを自由に決定できる
  - スライスにラベルを付ける
    - [x] v 順序付きリストでラベル名を付ける
      - [ ] スライスの色を変えられる
  - ドキュメント化
    - [x] v 通常のMarkdownの中にStoryMap文法を混ぜることができる。
      - [x] ^ アウトラインに表示されないコメントを書くことができる。
    - [x] v その他のメモを、アウトラインの上のパラグラフに書くことができる。
      - [x] ^ その他のメモを、アウトラインの下のパラグラフに書くことができる。
- マップを眺める #開発者 #コミュニティ
  - 眺める
    - [x] 開いた時点のアウトラインを元にマップ表示のプレビューを開く
      - [x] タスクの完了チェックが反映される
        - [x] ^ 編集に追従してプレビューが即時更新される
          - [x] ^ アウトラインの上のパラグラフは、マップの上に表示される。
            - [x] ^ アウトラインの下のパラグラフは、マップの下に表示される。
              - [ ] カードが紙に手描きしたように見える（気軽さ・温かみのため）
  - 操作する
    - [x] v マップをズームする
      - [ ] 倍率を手動で入力する
  - 保存する
    - [x] ストーリーマップをPNGで保存する
- マップから実装を進める #開発者
  - 次のゴールのタスク群を確認する
    - [x] v 完了したタスクにチェックをつける
  - 次に実装するタスクを選ぶ
    - [x] v 次のタスクにチェック欄を追加
