# User Story Mapping 拡張機能のストーリーマップ

<!-- 書式: 時系列は上から下（アクティビティの並び順）、タスクの重要度はネストの深さ（浅い＝左＝重要、深い＝右＝低い） -->
<!-- 本来はVSCode拡張機能（本プロダクト）で行うが、開発のブートストラップとして今回のみこのファイルを用いる -->

- 拡張機能を準備する
	- 拡張機能を.vsixファイルからローカルPCにインストールする
		- 拡張機能をVSCode Marketplaceからインストールする
- マップを用意する
	- [x] テスト用のマップを用意する
		- 新しいマップのMarkdownファイルを作る
			- 既存のアウトラインのMarkdownファイルをマップとして扱う
- アウトラインを書く
	- [x] テスト用のマップを開く
		- アクティビティを書き出す
			- アクティビティの順番を入れ替える
		- アクティビティの下にタスクを書き足す
			- タスクの重要度（ネストの深さ）を変える
- マップを眺める
	- [x] 開いた時点のアウトラインを元にマップ表示のプレビューを開く
		- 編集に追従してプレビューが即時更新される
			- 設定で横軸ストーリーごとの色を変える
				- タスクの完了チェックが反映される
    	- マップをズーム・スクロールする
        - ストーリーマップをPNGで保存する
- マップから実装を進める
	- [x] 最上段（Walking Skeleton）のタスク群を確認する
		- 完了したタスクにチェックをつける
			- 次に実装するタスクを選ぶ
