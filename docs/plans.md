## `story map`を含むHeading以降だけをストーリーマップとして扱う

`## story map`、`### Story Map`など、`story map`（大文字小文字は区別しない）を含むHeading以降の内容だけをストーリーマップのルールで扱う。該当するHeadingがなければ、従来どおり冒頭から扱う。

判定は、見出しの文字列をtrimした上で`/^story\s+map$/i`に一致するかで行う。範囲は次の見出しまで。

- [x] `## Story Map`の見出しより前にあるリストの項目は、カードにならない
- [x] `## Story Map`の見出しより後にあるリストの項目は、カードになる
- [x] 該当する見出しがなければ、冒頭からストーリーマップとして扱う（既存テストが担う）
- [x] マップのタイトルは文書の最初の見出しのまま（`## Story Map`ではない）
- [x] 補足のパラグラフは、`## Story Map`より後で最初のリストより前のものだけを表示する
- [x] レベル名の順序付きリストは、`## Story Map`より後のものだけを使う
- [x] 次の見出しが来たらストーリーマップの範囲は終わり、その後のリストはカードにならない
- [x] 見出しの一致は大文字小文字を区別しない（`story map`、`STORY MAP`も一致）
- [x] `My Story Map`のように前後に語がある見出しは一致しない
- [x] PNGのファイル名に使うmapTitleも文書の最初の見出しのまま

## `//`で始まるアイテムをマップ上で無視する

カードにまつわる背景や考えたことをアウトラインに書いたまま、マップでは非表示にできるようにする。`//`で始まるアイテムは、マップ上では完全に無視される。

子もまとめて無視する（インデントの整合のため）。無視したアイテムは内部カラムや行の数に影響しない。`//`の直後の空白は不要（`//memo`も無視）。対象はリストのアイテムだけ。

- [x] `//`で始まるアイテムはカードにならない
- [x] `//`で始まるアイテムの子孫もカードにならない
- [x] 無視したアイテムは内部カラムに影響しない（同じ深さの次の兄弟は、無視したアイテムがないときと同じカラムに来る）
- [x] 無視したアイテムは行数に影響しない（`+`の下にある`//`の子は行を増やさない）
- [x] `//memo`のように直後に空白がなくても無視される
- [x] トップレベルの`//`アイテムは子ごと無視され、カラムを作らない
- [x] `//`で始まるパラグラフは対象外で、補足として表示される
- [x] READMEの文法一覧に`//`メモの行を追記する（テスト対象外・記録）
