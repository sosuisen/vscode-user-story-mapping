## 空白レベルの目印を `_` にする（ADR 003）

- [x] `- _` のアイテムは空白レベルとして扱われ、カードにはならず、その下のタスクはレベルが1つ深くなる
- [x] CRLF改行のアウトラインでも `- _` は空白レベルとして扱われる
- [x] テキストに `_` を含むだけのアイテム（例: snake_case）は通常のカードになる
- [x] 内容のない `- ` だけの行は空白レベルにならない（CommonMarkの解釈に任せる）
- [x] `_` の前後に半角スペースがあっても（`-  _  `）空白レベルとして扱われる

## 補足事項と横断タスクのパラグラフ

- [ ] 補足事項はタイトルの下にパラグラフとして表示される（アウトラインより上のパラグラフ）
  - [x] アウトラインより上のパラグラフが、タイトルの下・グリッドの上に段落（map-note）として表示される
  - [x] パラグラフが複数あれば、アウトラインの順に段落が並ぶ
  - [x] 段落の中のインライン記法（強調など）が反映される
  - [x] 見出しがなくても、アウトラインより上のパラグラフは段落として表示される
  - [x] アウトラインより下のパラグラフは、補足事項の段落にはならない
- [ ] 全ストーリーにかかる横断的なタスクを、アウトラインの下のパラグラフに書くことができる
