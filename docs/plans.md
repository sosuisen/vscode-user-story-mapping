## スライスの移動を `^` と `v` に統一（ADR 005）

- 仕様: 子のマーカー `^`（親と同じスライス）、`v`×n（n スライスあける）。直後の空白必須。`- [ ] ^ タスク` の順。兄弟ごとに判断。列には影響しない。`+` と `_` は廃止
- 新文法
  - [x] `- ^ Task` の子は、親と同じ帯の1つ下の行に置かれる。`^` はカードに表示されない
  - [x] `^` の子の子（マーカーなし）は、次の帯に置かれる
  - [x] `^` が連鎖すると、同じ帯のまま行が1つずつ下がる
  - [x] 兄弟のうち `^` の付いた子だけが親の帯に入る。付かない子は1つ下の帯
  - [x] `^` の子の兄弟は右の列に並ぶ（マーカーは列に影響しない）
  - [x] `- v Task` の子は、親の2つ下の帯に置かれる。`v` はカードに表示されない
  - [x] `- vvv Task` の子は、親の4つ下の帯に置かれる（三角測量）
  - [x] `v` で飛ばした帯も描画される
  - [x] `v` の子の子（マーカーなし）は、さらに1つ下の帯に置かれる
  - [x] `- [x] ^ Task`: チェックボックスの後にマーカーを書く。⬜ と todo のまま親の帯に入る
  - [x] `- [x] v Task`: ✅ と done のまま2つ下の帯に入る
  - [x] `- ^ Task #tag`: タグと併用できる
  - [x] 直後に空白がないもの（`^Task`、`vsCodeを開く`）はマーカーではなく、通常のカードになる
  - [x] `^^ Task` はマーカーではなく、通常のカードになる
  - [x] トップレベル（アクティビティ）の `^`/`v` は、マーカーを外して既定の位置に置く（要確認）
- 廃止
  - [x] 行末の `+` はマーカーではなくなり、本文として表示される。子は1つ下の帯
  - [x] `_` だけのアイテムは、通常のカードになる
  - [x] 既存の `+` テストと `_` テストを新文法で語り直す、または削除する
- ドキュメント
  - [x] README（日英）の文法説明と例を書き換える
  - [x] 図を作り直す（plus と blank は caret と v に置き換え。syntax 日英も再生成）
  - [x] test/test.md、test/sample.md、docs/storymap.md を新文法に書き換える
