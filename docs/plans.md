# Plans

現在TDDの対象としているtodo（作業用・使い捨て）。

## タグ

- [x] リスト項目には末尾に複数のハッシュタグを追加できる。 #tag1 #tag2
- [x] タグは、背景色白で角丸で囲まれて末尾に表示される。
- [x] 行末の `+` とタグを併用できる（`- Task #tag1 +`）。タグは表示され、子は同じレベルに置かれる

## レベルのタイトル

- [x] レベルの左端にはタイトルが表示される。
  - [x] ドキュメントにOrdered list が含まれる場合、1,2,3,4...の順に上のレベルからのタイトルを表すものとする。なければタイトルはなし。
  - [x] 指定のない場合、デフォルトでは上から「1. Backbone」「2. Walking Skeleton」「3. Next Goal」4以下はない。
  - [x] Ordered listはアウトラインより下に置いてもタイトルになる
  - [x] 存在しないレベルのタイトルは描画されない（Ordered listがレベル数より長くても余りは表示しない）
