# oecha

運用者（サイトを立てて仲間を招く人）と参加者（招かれて描く人）の 2 種類のユーザーがいる。
左から右へ、運用者が場を用意してから、参加者が描き、会話し、見返し、運用者が場を守るまでの流れで並べた。
最上段（各アクティビティの 1 段目）が Walking Skeleton。

- サイトを立てる
	- [ ] GitHub リポジトリを自分の Cloudflare アカウントに手動で登録し、サイトを展開する
		- 管理者としてパスキーで登録する
			- Deploy to Cloudflare ボタン一つでサイトを展開する
				- サイトを更新する（新しい版を取り込む）
    		- サイトの名前を決める
- 仲間を招く
	- [ ] 管理者は新たに部屋を作る
   		- 管理者はキャンバスのサイズを決める
			- 複数の部屋を管理できる
    - [ ] 招待コードを発行して、仲間に配る
        - 招待コードの有効期限や人数を決める
- 部屋に入る
	- [ ] 招待コードを入力し、表示名を決めて部屋に入る    	
       	- 自分の表示名やアイコンを変える
    		- パスキーで登録し、2 回目以降はパスキーだけで入る			
        		- 別の端末（iPad）からも同じ名前で入る
- 描く+
    - 自分が描く
    	- [x] 自分のレイヤーにペンで線を引く+
    		- [x] 消しゴムで自分の線を消す
        		- [x] ペンの太さを変える+
            		- [x] 自分のレイヤーが2枚あって、切り替えられる。+
                    	- 直前の線を取り消す（Undo）+
                        	- ペンの色を変える
                            	- ボードを拡大縮小・移動して、空いた場所を探す+
                            		- 他の人のレイヤーの表示と非表示を切り替える
    - 他の人が描く
    	- [ ] 他の参加者が描いた線が、描き終わってすぐ自分の画面に現れる。
- 会話する
	- [ ] チャット欄に文字を書き、全員に届く
		- 誰が今いるかを見る
			- 誰がどこを描いているかを名前で知る
				- チャットの過去ログを読む
- 見返す
    - 完成したボードを画像として保存する
    	- 途中から入っても、それまでのボードが同じ形で再現される+
        	- 過去の部屋のボードを後日開く
            	- ボードの描かれた過程を最初から再生する
        			- 再生を早送り・一時停止する
					
- 場を守る
	- [ ] 招待コードを無効にする
		- 参加者を部屋から追放する
			- 追放した参加者のレイヤーを消す
				- 部屋を閉じて、新しい参加を止める
